`OrchestraConductor` includes Unity project content and third-party assets that are not relicensed under the repository's MIT license unless their original license explicitly allows it.

## Included dependencies and assets

- Unity Engine, Unity Editor, and Universal Render Pipeline packages are governed by Unity's own terms and package licenses.
- TextMesh Pro content under `Assets/TextMesh Pro/` is provided through Unity and remains subject to Unity's package terms.
- `Assets/PolyOne/People Lowpoly/` contains third-party character assets imported by the project owner. Redistribution must follow the original asset-store or author license.
- Audio files under `Assets/Audio/` are project content and should only be redistributed if you control the rights to those recordings.
- Imported texture/material sources such as parquet and carpet images remain subject to the license terms of their original download source.

## Distribution guidance

- The repository source code is licensed under MIT in [LICENSE](LICENSE).
- Third-party art, audio, and package content keep their own licenses.
- Before publishing commercial or public builds, verify every asset license in your original download receipts, Unity Asset Store records, or source package documentation.

## Practical release recommendation

If you want a fully clean open-source release, keep the code public but replace any third-party audio or art assets whose redistribution rights are uncertain.
